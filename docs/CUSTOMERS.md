# تسليم النظام لعميل (نسخة مستقلة لكل عميل)

كل عميل عنده حساب Vercel وقاعدة بيانات ومفاتيح خاصة فيه. بياناته ما تمر على أي حساب غيره.

## قبل ما تبدأ (مرة وحدة)
- اجعل المستودع **Public** (GitHub ← Settings ← Danger zone ← Change visibility)، وإلا زر النشر ما يشتغل عند العميل.
- جرّب زر النشر مرة من نافذة Incognito بحساب Vercel جديد. إذا طلع خطأ في خطوة قاعدة البيانات احذف `stores` من رابط الزر في `web/app/page.tsx` وخلّ العميل يضيف Upstash يدوياً.

## الخطوات مع كل عميل (حوالي 10 دقائق)
1. العميل ينشئ حساب Vercel (Hobby مجاني) ويربطه بحساب GitHub.
2. يضغط **ولّد كلمتي السر** في الصفحة الرئيسية (تنولد في متصفحه فقط) ويحفظهم، ثم يضغط **انشر نسختك** ويلصقهم في `MCP_SECRET` و `CRON_SECRET`.
3. قاعدة البيانات: Storage ← Create ← Upstash ← Redis ← الخطة المجانية ← Connect ثم Redeploy. لو الخطة المجانية ما ظهرت (قاعدة مجانية وحدة لكل حساب Upstash) أنشئ واحدة من console.upstash.com وضع `KV_REST_API_URL` و`KV_REST_API_TOKEN` يدوياً.
4. في Vercel ← Settings ← Deployment Protection: يوقف الحماية (Vercel Authentication) عن النشر الإنتاجي، وإلا Claude ما يقدر يوصل للرابط.
5. إضافة المتغيرات الاختيارية ثم Redeploy:
   - `ANTHROPIC_API_KEY` للمساعد بـ Claude، أو `AI_COMPAT_URL` و `AI_COMPAT_KEY` و `AI_COMPAT_MODEL` لمزود أرخص.
   - `AI_MAX_PER_DAY` حد يومي لطلبات الذكاء (الافتراضي 300).
6. (قبل الربط) يفتح `/personal` ويضغط **اختبر الذكاء الاصطناعي** ليتأكد إن المفتاح واسم الموديل صحيحين.
7. العميل يفتح `https://<نسخته>.vercel.app/personal` ويدخل `MCP_SECRET`، يكتب رقمه ويدخل الرمز في واتساب (الأجهزة المرتبطة ← الربط برقم الهاتف).
8. من نفس الصفحة ينشئ مفتاح جهاز وينسخ الرابط الجاهز لـ Claude أو Cursor.
9. اختياري: قاعدة المعرفة، الفلوات (ابدأ بوضع «مسودة»)، الموصلات.

## نقاط تنبّه لها
- الرابط المنسوخ فيه المفتاح، فهو مثل كلمة سر. لو تسرّب ألغِ المفتاح من الصفحة.
- Vercel Hobby فيه مهمة مجدولة مرة باليوم فقط. للمزامنة الأسرع ربط خدمة نبض خارجية مجانية بالرابط `/api/cron/sync?key=<CRON_SECRET>`.
- ربط حساب شخصي عبر مكتبة غير رسمية قد يعرّض الرقم للتقييد؛ ينصح العميل بالاستخدام المعتدل.
- لا تحتفظ أنت بأي من مفاتيح العميل. لو احتجت تدعمه اطلب منه لقطة شاشة من صفحة `/personal` بدون المفاتيح.

## التحديثات
نسخة العميل ربطت بنسخة من المستودع عند النشر. للتحديث: GitHub ← Sync fork (أو أعد النشر من المستودع الأصلي)، وVercel يعيد البناء تلقائياً.

## أتمتة إنشاء مشروع عميل (عندما تديره في حسابك أو فريقك)
سكربت يسوي مشروع Vercel جديد من هذا المستودع بمتغيراته، ويطفي حماية النشر، وينشره:

```bash
export VERCEL_TOKEN=...            # Vercel > Settings > Tokens
export CUSTOMER_AI_KEY=...         # مفتاح الذكاء الخاص بالعميل (متغير بيئة، مو وسيط)
node web/scripts/new-customer.mjs --name acme --ai deepseek [--team team_xxx] [--dry-run]
# مع قاعدة جاهزة: --redis-url https://... مع REDIS_TOKEN=...
```
- يولّد `MCP_SECRET` و`CRON_SECRET` ويطبعهم **مرة وحدة** في آخر المخرجات لتسلمهم للعميل.
- لو ما مرّرت قاعدة Redis، اربطها من Vercel ← المشروع ← Storage ← Upstash Redis ← Connect ثم Redeploy. **لا تشارك قاعدة بين عميلين.**
- جرّب أول مرة بـ `--dry-run` (ما ينشئ شي).
- ملاحظة شروط: خطة Hobby للاستخدام غير التجاري. لإدارة مشاريع عملاء مدفوعين في حسابك تحتاج Pro.
